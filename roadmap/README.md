# Goblin News roadmap

This folder holds only the data. The page design and the build script are shared by every
project and live in the Command Center roadmap kit:

    /home/mike/dev/command-center/integrations/roadmap-kit/   (README.md there has the schema and rules)

| File | Role |
|---|---|
| `roadmap.json` | The single source of truth. Edit this. |
| `roadmap.html`, `roadmap.fragment.html` | Generated by the kit. Never edit by hand. |

## Update

1. Edit `roadmap.json` and set `updated` to today. Keep item `id`s stable: Mike's notes and
   steering in Command Center are attached to them.
2. Rebuild:

       python3 /home/mike/dev/command-center/integrations/roadmap-kit/build_roadmap.py --json roadmap/roadmap.json

3. Commit `roadmap.json` and the generated files together. Command Center shows the new
   version by itself; do not copy it to the outbox.

Do not add a template or build script here and do not redesign the page. If the design should
change, tell Mike; it is changed once in the kit for all projects.

Track order in `roadmap.json` sets the colours (the first three listed get their own colour),
so keep `trends`, `audience`, `trackers` first.
